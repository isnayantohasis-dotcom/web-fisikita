PANDUAN PENAMAAN FILE GAMBAR — FISIKITA
=========================================

Semua gambar (foto profil, dokumentasi kegiatan, thumbnail lab/gim/media)
ditaruh SEJAJAR dengan file-file HTML (folder yang sama, TIDAK perlu
bikin folder "images" lagi — supaya lebih gampang di-upload lewat GitHub).

ATURAN PENAMAAN FILE:
- Huruf kecil semua
- Tanpa spasi -> pakai tanda hubung (-)
- Tanpa karakter aneh (é, ñ, &, %, dst)
- Ekstensi: .jpg untuk foto, .png untuk gambar dengan latar transparan

CONTOH YANG BENAR:
  foto-profil.jpg
  kegiatan-pelatihan-gim.jpg
  kegiatan-workshop-ai.jpg
  lab-gerak-parabola.png
  gim-tebak-satuan.png
  media-animasi-newton.jpg

CONTOH YANG SALAH (hindari):
  Foto Profil.jpg        -> ada spasi & huruf besar
  kegiatan_2026#1.JPG     -> underscore, simbol, ekstensi kapital
  IMG_20260724_143210.jpg -> nama bawaan kamera, tidak deskriptif

-----------------------------------------
NAMA FILE YANG SUDAH DITUNGGU KODE SAAT INI:
-----------------------------------------
1. Foto profil guru (halaman profil.html):
   foto-profil.jpg
   -> tinggal upload file dengan nama PERSIS ini ke folder utama repo
      (sejajar dengan index.html), otomatis muncul menggantikan ikon
      avatar. Kalau belum ada, otomatis fallback ke ikon.

2. Dokumentasi kegiatan (halaman profil.html, array KEGIATAN):
   isi field "image" pada tiap objek kegiatan, contoh:
   image: 'kegiatan-pelatihan-gim.jpg'

3. Thumbnail Lab Maya / Gim Edukasi / Media Interaktif:
   isi field "image" pada array LABS / GAMES / MEDIA, contoh:
   image: 'lab-gerak-parabola.png'

Kalau field "image" dikosongkan (''), otomatis pakai ikon+gradien
bawaan — jadi tidak akan pernah tampil kosong/error.

CARA UPLOAD KE GITHUB:
Cukup drag file gambar ke halaman utama repo (sama seperti upload
file HTML), TIDAK perlu bikin folder apa pun.
