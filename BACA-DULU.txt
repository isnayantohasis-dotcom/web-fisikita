- Tanpa spasi -> pakai tanda hubung (-)

- Ekstensi: .jpg untuk foto, .png untuk gambar dengan latar transparan

-----------------------------------------
NAMA FILE YANG SUDAH DITUNGGU KODE SAAT INI:
-----------------------------------------
1. Foto profil guru (halaman profil.html):
   images/foto-profil.jpg
   -> tinggal taruh file dengan nama PERSIS ini, otomatis muncul
      menggantikan ikon avatar. Kalau belum ada, otomatis
      fallback ke ikon (tidak akan error/gambar rusak).

2. Dokumentasi kegiatan (halaman profil.html, array KEGIATAN):
   isi field "image" pada tiap objek kegiatan, contoh:
   image: 'images/kegiatan-pelatihan-gim.jpg'

3. Thumbnail Lab Maya / Gim Edukasi / Media Interaktif:
   isi field "image" pada array LABS / GAMES / MEDIA, contoh:
   image: 'images/lab-gerak-parabola.png'

Kalau field "image" dikosongkan (''), otomatis pakai ikon+gradien
bawaan — jadi tidak akan pernah tampil kosong/error.
